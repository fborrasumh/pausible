CRITERIOS   ESPECÍFICOS DE   CORRECCIÓN

PROBLEMA 1:

Determinación de la matriz X: planteamiento del problema (despejar la matriz) de 0 a 1 punto, cálculos de 0
a 0.5 puntos. Determinación de la matriz Y: aplicación correcta del método de resolución de 0 a 0.25 puntos,
cálculos de 0 a 0.25 puntos.

PROBLEMA 2:

Apartado (a): Planteamiento del problema de 0 a 0.75 puntos. Determinación valores solución: de 0 a 0.25
puntos.

Apartado (b): Planteamiento del problema (despejar la matriz): de 0 a 0.75 puntos. Resolución numérica de
0 a 0.25 puntos.

PROBLEMA 3:

Planteamiento del sistema de ecuaciones: de 0 a 1.5 puntos. Resolución numérica: de 0 a 0.5 puntos.

PROBLEMA 4:

Planteamiento del problema: de 0 a 0.75 puntos. Determinación de la región factible: de 0 a 0.5 puntos.
Determinación del punto óptimo y solución final: de 0 a 0.75 puntos.

PROBLEMA 5:

Planteamiento del problema: de 0 a 1.5 puntos. Determinación de A y B: de 0 a 0.5 puntos.

PROBLEMA 6:

Apartado (a): Cálculo de extremos relativos: de 0 a 0.5 puntos. Determinación del máximo y del mínimo
absoluto: de 0 a 0.5 puntos. Determinación del valor de C(x) en el máximo y el mínimo absoluto de 0 a 0.25.
Contextualización de la solución final: de 0 a 0.25.

Apartado (b): Representación gráfica: de 0 a 0.5 puntos.

PROBLEMA 7:

Determinación puntos de corte: de 0 a 0.25. Representación gráfica: de 0 a 0.25. Cálculo de primitiva: de 0
a 0.5 puntos. Aplicación Regla de Barrow: de 0 a 0.5. Cálculo del área: de 0 a 0.5 puntos.

PROBLEMA 8:

Apartado (a): De 0 a 1 punto.

Apartado (b): De 0 a 1 punto.

PROBLEMA 9:

Apartado (a): De 0 a 1 punto.

Apartado (b): De 0 a 1 punto.

PROBLEMA 10:

Apartado (a): Planteamiento del problema: de 0 a 1.25 puntos. Resolución numérica: de 0 a 0.25 puntos.

Apartado (b): De 0 a 0.5 puntos.

Nota.   En la calificación de cada problema se tendrá en consideración la exposición del razonamiento

utilizado, la justificación de las respuestas y la interpretación de los conceptos y de los resultados básicos.
