Prueba   de Evaluación de Bachillerato

para el Acceso a la Universidad (EBAU)

Universidad de Extremadura

Curso 2023-2024

Materia: Matemáticas Aplicadas a las Ciencias Sociales II   Tiempo máximo de la prueba: 1h 30 min

CRITERIOS ESPECÍFICOS DE CORRECCIÓN

PROBLEMA 1:

Planteamiento del problema (despejar la matriz): de 0 a 1.25 puntos. Resolución numérica: de 0 a 0.75
puntos.

PROBLEMA 2:

Apartado (a): Planteamiento del problema de 0 a 1 punto. Determinación valores solución: de 0 a 0.5

puntos.

Apartado (b): De 0 a 0.5 puntos.

PROBLEMA 3:

Planteamiento del sistema de ecuaciones: de 0 a 1.5 puntos. Resolución numérica: de 0 a 0.5 puntos.

PROBLEMA 4:

Planteamiento del problema: de 0 a 0.75 puntos. Determinación de la región factible: de 0 a 0.5 puntos.
Determinación del punto óptimo y solución final: de 0 a 0.75 puntos.

PROBLEMA 5:

Planteamiento del problema: de 0 a 1.5 puntos. Determinación de A y B: de 0 a 0.5 puntos.

PROBLEMA 6:

Apartado (a): Cálculo de extremos relativos: de 0 a 0.75 puntos. Determinación de extremos absolutos:
de 0 a 0.5 puntos. Contextualización de las soluciones finales: de 0 a 0.25.

Apartado (b): Representación gráfica: de 0 a 0.5 puntos.

PROBLEMA 7:

Estudio de asíntotas horizontales/oblicuas: de 0 a 1 punto. Estudio de asíntotas verticales: de 0 a 1 punto.

PROBLEMA 8:

Apartado (a): De 0 a 1 punto.

Apartado (b): De 0 a 1 punto.

PROBLEMA 9:

Apartado (a): De 0 a 1 punto.

Apartado (b): De 0 a 1 punto.

PROBLEMA 10:

Apartado (a): De 0 a 1 punto.

Apartado (b): Estimación puntual: 0.25. Planteamiento del problema: de 0 a 0.5 puntos. Resolución
numérica: de 0 a 0.25 puntos.

Nota.   En la calificación de cada problema se tendrá en consideración la exposición del razonamiento

utilizado, la justificación de las respuestas y la interpretación de los conceptos y de los resultados básicos.
